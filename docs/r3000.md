# R3000 — Rozkurwator 3000

> A pipeline language for wrecking data on purpose: fuzzing inputs, mangling fixtures, chaos tests. Data goes in at `rozwal`, passes through `|>` stages, and leaves at `wypluj`.

| Field | Value |
|---|---|
| Type | programming |
| Color | `#b83a3a` |
| Extensions | `.r3k` (primary), `.r3000` (presets), `.rzk` (short form) |
| Output artifact | `.r3x`: a wrecked file plus a JSON sidecar with the seed and stage list. It is binary and not tracked by Linguist |
| MIME | `text/x-r3000` |
| Signature | `;; R3000` comment, or a shebang that names `r3k` / `rozkurwator` |
| Interpreters | `r3k`, `rozkurwator` |
| TextMate scope | `source.r3000` |

## Directives (metadata)
| Directive | Meaning |
|---|---|
| `moc N` | power level, 1–3000. It scales how destructive the stages are. Behaviour above 9000 is undefined. |
| `tryb "ostrozny"\|"chaos"\|"totalny"` | mode: careful, chaos or total |
| `;; @key value` | free metadata in comments, e.g. `;; @wersja 1.0 @licencja MIT` |

## Syntax
```r3000
;; R3000 — Rozkurwator 3000
moc 3000
def podwoj x => x * 2                  ; function

rozwal "in.bin"                        ; source ("-" = stdin)
  |> tnij 64                           ; cut into 64-byte chunks
  |> mieszaj ziarno: 1337              ; shuffle, named argument
  |> zgniec "zstd"                     ; compress
  |> wypluj "out.r3x"                  ; sink ("-" = stdout)

petla i od 1 do 3 { jesli i == 3 { wypisz "BOOM" } inaczej { wypisz (podwoj i) } }
!!! "pełne rozkurwienie"               ; panic
```

Stages: `rozwal` (open), `tnij` (cut), `mieszaj` (shuffle), `zgniec` (squash), `odwroc` (reverse), `powiel` (repeat), `filtruj` (filter), `mapuj` (map), `los` (random), `wypluj` (write) and `wypisz` (print).
Control: `petla … od … do`, `jesli` / `inaczej`, `zwroc`. Constants: `prawda`, `falsz`, `nic`.
